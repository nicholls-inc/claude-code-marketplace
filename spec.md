# Specification: pr-swarm Plugin Integration & Governance

**Tier**: 2 (Standard)
**Governing Intent**: [`intent/2026-09-18-pr-swarm-plugin.md`](intent/2026-09-18-pr-swarm-plugin.md)
**Component**: `pr-swarm`
**Status**: Implemented

---

## 1. Overview & Objective

Integrate the `pr-swarm` plugin into the Claude Code Plugin Marketplace as a first-class, project-agnostic plugin. The plugin provides a router-first, multi-agent pull request review swarm (`/pr-swarm`) and an automated review feedback triage loop (`/review-triage`).

This specification covers:
1. Marketplace registration in `.claude-plugin/marketplace.json`.
2. Release automation setup in `release-please-config.json` and `.release-please-manifest.json`.
3. Repository onboarding and documentation in `README.md` and `CLAUDE.md`.
4. Governance, safety invariants, and verification criteria.

---

## 2. Marketplace Registration

### File: `.claude-plugin/marketplace.json`
The plugin catalog must include a new entry for `pr-swarm` within the `plugins` array:

```json
{
  "name": "pr-swarm",
  "source": "./pr-swarm",
  "description": "Multi-agent PR review swarm and review-triage skills for automated, multi-lens code reviews."
}
```

- **Name**: `pr-swarm`
- **Source**: `./pr-swarm` (relative directory within the repository)
- **Description**: Concise summary highlighting multi-agent PR review and triage.

## 5. Safety Invariants & Governance

The `pr-swarm` plugin enforces five primary invariants:

1. **INV-1: Sovereign Human Approval**:
   Neither `/pr-swarm` nor `/review-triage` will ever submit an approving GitHub review (`event=APPROVE`). Reviews are posted with `event=COMMENT` exclusively.
2. **INV-2: Single Sticky Summary**:
   A single top-level PR comment is maintained idempotently using the marker `<!-- pr-swarm-summary -->`.
3. **INV-3: Human-Participation Gate**:
   Automated triage strictly defers any review thread where a human reviewer has participated, preventing unsolicited bot intervention.
4. **INV-4: Loop Prevention Git Trailer**:
   All automated commits generated by `/review-triage` include the trailer `PR-Swarm-Automated: true`.
5. **INV-5: Scrubbing & Zero Leaks**:
   All files in `pr-swarm/` are project-agnostic with zero occurrences of internal organization identifiers or private fixtures.
